# Bangun pipeline sendiri, bukan membeli Voynan

Voynan menjual paket skill yang hasilnya setara dengan target kita (Rp109.000 untuk bundle). Kita sengaja membangun pipeline sendiri. Pipeline ini akan menjadi dasar jasa edit konten untuk klien, jadi stack, gaya, dan aset (library ilustrasi, brand kit) harus milik dan dikendalikan sendiri. Pipeline juga harus bisa disesuaikan per klien tanpa bergantung pada produk pihak lain. Voynan hanya dipakai sebagai referensi kualitas visual. Kode atau aset mereka tidak disalin.
